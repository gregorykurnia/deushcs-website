# Delami logo sources

Entity check: PT Delamibrands Kharisma Busana (formerly PT Delami Garment Industries, current name since 2016) owns/distributes Wood, Executive, Colorbox, Et Cetera, Tirajeans, Jenahara and holds the Wrangler distribution licence for Indonesia. The brand list matches what delamibrands.com itself shows (brand pages at delamibrands.com/brands/<brand>/), so all logos below are the Delami-site versions of each brand, not same-named unrelated brands.

Main files are dark (black) on transparent, for a light website. "-white-*" files are the white-on-transparent versions the Delami homepage uses on dark photo banners; they are larger, and can be recoloured black without resampling (`convert in.png -fill black -colorize 100 out.png` keeps the alpha).
