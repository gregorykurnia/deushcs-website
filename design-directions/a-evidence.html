Evidence

The current DEUS brand, edited down. Navy carries the weight, orange marks the one thing that matters on each screen, and every layout is built on a strong left edge and hairline rules. It reads like a consulting firm that also ships software.

Color

Two inks and one accent. Orange is a marker, never a fill larger than a button. Small orange text uses the darker Orange ink so it passes contrast on white.

Navy#0B1A44

Headings, primary buttons, dark panels. 16.9:1 on white.

Slate#525F78

Signal orange#F2552C

Accent CTA, markers, current step.

Orange ink#C2401B

Small orange text. 5.2:1.

Typography

One family, Plus Jakarta Sans, designed by Tokotype in Jakarta. Headlines are ExtraBold with tracking that tightens as the size grows. No monospace and no all-caps labels; small labels are sentence case in orange ink.

Principles

What changes from the current guide, and what stays.

    Keep

  • Navy, not black. Ink is #0B1A44; muted copy is slate.
  • One orange moment per view. The current step, the main button, a key number.
  • Hairlines before boxes. Rules separate lists; cards only for product UI.

    Change

  • Drop the mono eyebrows. Sentence-case labels, used only where they add meaning.
  • Drop the dot grid and glows. White space and real product data do the work.
  • Show product data, not device mockups. Clean UI cards built in code, crisp at any size.
